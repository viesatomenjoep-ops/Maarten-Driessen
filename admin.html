Supabase

Je SQL backend, auth en realtime. Plak je project URL en anon key — we slaan ze enkel in je browser op (localStorage).

Cloudinary

Je media library voor foto's en video's. Geef cloud name & een unsigned upload preset — klanten kunnen dan direct foto's uploaden.
